# coastal

vcv rack plugins made by jules

## modules

### daisy

stereo grain delay module with additional cv, based on ableton live's grain delay

### dew

simple compressor module with additional cv, based on ableton live's cytomic glue compressor

### petal (coming soon)

advanced dattoro-plate reverb module
